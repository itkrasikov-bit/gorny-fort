# «Горный Форт» — лендинг страйкбольного полигона

Одностраничный сайт с записью на игру и приёмом заявок. Без сборки, фреймворков и внешних
зависимостей: открывается двойным щелчком по `index.html` или загружается на любой статический
хостинг.

**Демо:** https://itkrasikov-bit.github.io/gorny-fort/

## Что есть на сайте

- **Первый экран** с ключевым оффером, афишей, счётчиком свободных слотов и контактами.
- **Как это работает** — четыре шага записи.
- **Форматы 3×3 и 4×4** — описания, состав команды, запись в один клик.
- **Расписание и запись** — 9 часовых слотов, занятые/свободные, выбор мышью или в селекте,
  живой расчёт стоимости шаров и защита от переполнения слота.
- **Снаряжение** — весь комплект бесплатно, цена только за шары.
- **Безопасность** — инструктаж, защита, контроль правил.
- **Сценарии** и блок для новичков.
- **Афиши** — 8 официальных афиш с полноэкранным просмотром и скачиванием.
- **Заявка на другое время** — отдельная форма.
- **FAQ** на нативных `details` (работает и без JS).
- **Панель заявок** — локальный список оформленных записей с экспортом в CSV.
- Адаптивная вёрстка (проверена от 390 до 1920 px), доступность, `prefers-reduced-motion`,
  sticky-меню, мобильная кнопка записи.

## Как открыть

- **Локально:** откройте `index.html` в браузере. Запись и заявки работают и по `file://`.
- **Через сервер (рекомендуется):**

  ```powershell
  cd D:\Fort\site
  npx http-server -p 8080 -c-1
  ```

  Затем откройте `http://localhost:8080`.

## Настройка

Всё, что чаще всего меняется, собрано в объекте `CONFIG` в начале `js/app.js`:

| Параметр | Назначение |
| --- | --- |
| `phoneDisplay`, `phoneRaw` | Телефон в тексте и в ссылке `tel:` |
| `telegram` | Ник в Telegram без `@` (ссылка `t.me/...`) |
| `ballsPrice`, `ballsPerPack` | Цена шаров: по умолчанию 150 ₽ за 50 шт. |
| `slotCapacity` | Сколько игроков вмещает один часовой слот (8) |
| `gameDate` | `null` — ближайшая суббота; `'2026-11-21'` — зафиксировать дату |
| `endpoint` | URL вашего бэкенда/бота: заявки уходят POST-запросом JSON (пусто — выключено) |
| `slots` | Шаблон расписания: начало, конец и демо-занятость `booked` |

Тексты, цены и контакты в разметке (`index.html`) продублированы в нескольких местах — при
изменении телефона или цены проверьте шапку, футер, блоки «Снаряжение» и FAQ.

### Даты

В исходном анонсе указано 14 ноября. Чтобы сайт не «устаревал», расписание по умолчанию
показывает **ближайшую субботу** (игры по выходным) и пересчитывает дату при загрузке страницы.
Нужна фиксированная дата — задайте `gameDate: '2026-11-21'`.
Занятость `booked: 8` у слотов 09:00, 10:00 и 13:00 — демонстрация состояний из анонса;
обнулите значения, когда будете вести реальное расписание.

### Как работает запись

1. Посетитель выбирает свободный слот и заполняет форму.
2. Заявка проверяется (имя, телефон, согласие, свободные места) и сохраняется в
   `localStorage` браузера под ключом `gornyfort.bookings.v1`.
3. Слот отмечается за вами в этом браузере: свободных мест в нём становится меньше, а заявка
   появляется в панели заявок.
4. Кнопка «Отправить в Telegram» копирует текст заявки и открывает чат с администратором —
   остаётся вставить и отправить. Данные никуда не уходят автоматически.

Это честное поведение статического сайта без сервера. Чтобы заявки приходили сами, укажите
`CONFIG.endpoint` — тогда каждая заявка дополнительно отправляется POST-запросом JSON на ваш
обработчик (Telegram-бот, CRM, Google Apps Script и т. п.).

### Панель заявок

Ссылка «Заявки на устройстве» в футере открывает локальный список записей: там же экспорт в CSV
(с BOM, разделитель `;` — открывается в Excel) и удаление. Данные не покидают браузер.

## Публикация

Папку `site` можно целиком загрузить на GitHub Pages, Netlify, Vercel, Cloudflare Pages или
обычный хостинг — достаточно статических файлов. Сборка не нужна.

## Материалы

Афиши предоставлены полигоном «Горный Форт»; изображения пережаты в WebP, для галереи сделаны
превью. Шрифты Oswald и Inter — Google Fonts, лицензия OFL, лежат локально в `assets/fonts`,
внешние запросы не нужны.
